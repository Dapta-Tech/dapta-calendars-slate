# Paths excluded from the trufflehog layer of scripts/publish-gate.sh (regex, one
# per line). ONLY documented placeholders / compose-internal dev defaults belong
# here — never a path that could carry a real credential.
#
# .env.example documents the DATABASE_URL shape with a placeholder URL; the
# compose files carry the well-known local dev credentials that the same files
# define themselves. TruffleHog can't verify them on the CI runner (no DB/DNS),
# so they land in the "unknown" bucket and fail the gate as false positives.
\.env\.example$
docker-compose\.yml$
docker-compose\.prod\.yml$
